# Elegantia — エレガンティア

「標準以下を出さない」を、具体的な観点と確かめられる証拠に変える審美眼ツールです。

アクションゲーム、3DCG、ハイグラフィックを中心に、操作の応答、待ち時間、情報の分かりやすさ、表現の一貫性まで、体験の質を見直します。美しく見せるだけでなく、迷わせず、待たせず、意図が伝わる体験を目指します。

## 3つの入口

| コンテンツ | 使いどころ |
|---|---|
| [アドバイザリー](advisory/README.md) | プログラム設計・企画設計で、採用すると良い指針を検討する。遵守は任意。 |
| [クォリティ](quality/README.md) | 品質が低いと判断される点を確認し、必須達成と追加達成を証拠で確かめる。 |
| [UXテンプレート](ux/README.md) | 目指す体験から必要な機能と品質を逆引きする。Ludusの機能定義を参照する。 |

## 品質を確かめる

[180項目の索引](quality/index.md)から、対象のカテゴリと項目を選びます。共通体験30、アクション45、3DCG40、グラフィック50、審美眼15を収録しています。3DCGは造形・リグ・アニメーション・素材・撮影・合成・納品を扱います。

各項目は「ポイント」「実装内容」「達成しうるUX」「品質達成要件」「追加達成要件」の同じ5見出しで構成します。目指す体験を定め、実装し、条件をそろえて試験し、結果と証拠を残すための共通言語です。

記録があることと品質を達成したことは別です。証拠の内容は人が確認します。Elegantiaはコンテンツを自動実行したり、証拠を自動審査したりするツールではありません。
